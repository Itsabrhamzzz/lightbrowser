Extensions

Chrome extensions, running in LightBrowser.

How extensions work here

Unpacked extensions: copy each one into its own folder inside the extensions folder, then press Load unpacked folders.

Popups & options: extensions can't add toolbar buttons here, so their popup and options pages open in a tab from the buttons on each card.

Compatibility: Manifest V3 extensions work best. Older Manifest V2 extensions (like the original uBlock Origin) may not load — try their "Lite" / MV3 versions.
